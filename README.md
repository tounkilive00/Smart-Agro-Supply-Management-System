# Smart Agro-Supply Management System

## 📋 Project Overview
A comprehensive PL/SQL-based database solution for agricultural supply chain management, enabling efficient tracking, allocation, and optimization of agricultural inputs across multiple farms and cooperatives.

### 🎯 Key Objectives
- Centralized inventory management for seeds, fertilizers, and equipment
- Demand forecasting based on seasonal trends
- Automated allocation to farms based on crop type and soil conditions
- Supplier and order management with BI capabilities
- Sustainable farming practice monitoring

### 📊 Problem Statement
Agricultural industries face significant challenges in managing supplies for multiple farms, leading to inefficiencies, stockouts, and increased costs. This system addresses these issues through automated inventory management and data-driven decision support.
